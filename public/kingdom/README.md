# ممالك حينا — حزمة واحة العهد

أصول أصلية بأسلوب low-poly، مرخصة CC0-1.0. جميع الشخصيات مجسمات ثابتة بدون rig أو حركات.

## التشغيل

من جذر المشروع: `python -m http.server 8080 --directory public`

افتح `http://localhost:8080/kingdom/`. لا تحتاج النسخة الفردية إلى حساب أو خادم بيانات. تتضمن بناء المنشآت، موارد كل دور، استهلاك الغذاء، تدريب الجيش، ترقية القلعة، معارك محسوبة، شرط انتصار وحفظًا يدويًا محليًا.

## الملفات

- ٦ شخصيات، ١٢ مبنى ومورد بيئي، ٤ أراضٍ، ٨ أيقونات أوامر وموارد، وخريطة كاملة.
- لكل أصل SVG وPNG شفاف 256×256 وICO وglTF 2.0 ببيانات هندسية مضمنة.
- `world-map.gltf` خريطة كاملة ثلاثية الأبعاد ١٠×١٠، و`world-map.svg` صورتها المصغرة.
- `manifest.json` فهرس الأصول الذي يستخدمه محرك اللعبة داخليًا؛ لا توجد واجهة عامة لتصفح أو تنزيل المجسمات.
- إعادة التوليد: `python scripts/build-kingdom-assets.py` من جذر المشروع.

هذه نسخة استراتيجية فردية مستقلة. لا تضيف تعدد لاعبين، ولا تستبدل شاشة Expo الحالية أو إجراءات Supabase. الدمج الأصلي مع التطبيق والحركات والاختبارات على الأجهزة مراحل إضافية. PING يُفسّر هنا بأنه PNG، وICON بصيغة ICO.
