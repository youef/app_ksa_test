# نظام حيّنا المدمج — iOS Compact

هذا النظام مطبّق على المكونات المشتركة وصفحات التطبيق. المرجع البرمجي هو lib/oasis.ts وcomponents/oasis/OasisPrimitives.tsx. ملفات PNG تمثل الأسطح؛ النصوص والأيقونات الحية تبقى مكونات قابلة للوصول، ولا تحدد الصور مقاسات عناصر التحكم.

| العنصر | المقاس المنطقي |
| --- | --- |
| زر نموذج | 44 حد أدنى |
| دخول أو إجراء بارز | 48 حد أدنى |
| زر أيقونة | مساحة لمس 44، الرسم 18–23 |
| شريحة تصفية | مظهر 32، مساحة لمس رأسية 44 باستخدام hitSlop |
| حقل سطر واحد | 44 حد أدنى |
| نص متعدد الأسطر | 100 حد أدنى ويكبر حسب السياق |
| شريط علوي | iOS: 44 + safe area؛ الويب: 48 |
| شريط تبويبات | 56 + safe area؛ اختيار تصميم خاص بالتطبيق |
| حواف الحقول / البطاقات / النوافذ | 10 / 14 / 20 |
| الخط | خط النظام؛ متن 14–16، عنوان 17–22، وصف صغير 11–13 |

الألوان: خلفية #F2F2F7، سطح #FFFFFF، نص #1C1C1E، ثانوي #636366، فواصل #E5E5EA، إجراء #047857. اللون الأحمر للأخطاء والإجراءات المدمرة، مع وصف نصي.

المحتوى بعرض كامل على الجوال وبحد 820 على الشاشات الواسعة؛ الإدارة والخريطة والبث تستعمل حدودًا أوسع. الحقول والأزرار تستعمل minHeight بدل تثبيت ارتفاع النص، وتبقى خاصية تكبير الخط الأصلية مفعلة. استعمل safe-area-insets الفعلية ولا تضع ارتفاع شريط الحالة يدويًا.

في الصفوف الأفقية العربية: اتجاه حاوية التمرير rtl، واتجاه المحتوى ltr مع row-reverse، ليظهر أول تبويب على اليمين ويمكن الوصول إلى الباقي.

المحادثة: زر أدوات يكشف الصور والموقع والشكر والردود السريعة، مع بقاء الكتابة والإرسال ظاهرين. لا تضف صف أيقونات دائمًا يضيّق حقل الرسالة.

ملفات mockups/ وoverview.png تصورات محفوظة من الإصدار السابق وليست لقطات للواجهة الحالية. ملفات buttons/ وfields/ وcards/ وheaders/ وnavigation/ وtokens.json محدثة للنظام المدمج. الأصول محفوظة بكثافات 1x و2x و3x حيثما يحدد الفهرس.

المرجع: https://developer.apple.com/design/tips/ وhttps://developer.apple.com/design/human-interface-guidelines/buttons . هذه قواعد تصميم مسترشدة بإرشادات Apple، وليست شهادة قبول من App Store. يلزم فحص جهاز iPhone وDynamic Type وVoiceOver قبل الإطلاق.
