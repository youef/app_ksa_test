# Saudi locations dataset

`cities.json` and `districts.json` provide the municipality location names used to fill out the region, city, and district selector. The source repository identifies the distributed dataset as CC0:

https://github.com/yasseralsamman/saudi-municipal-coding

The names are administrative-place data; they do not include coordinates for every neighborhood. For precise weather at a manually added place, an administrator can supply latitude and longitude in the admin location manager. Otherwise the app geocodes the selected city and retrieves current model-based weather for those coordinates.
