# تطوير الدليل وصفحة المنشأة

## التغييرات

- الدليل: بحث مؤجل 350ms، أنواع منشآت/خدمات، فلتر التوثيق، ترتيب الأحدث/الأبجدي، دفعات قابلة للاستكمال، تحديث بالسحب، وإعادة ضبط الفلاتر. نطاق المدينة والحي واعتماد المحتوى يطبّق قبل pagination على المصدرين. الترقيم وجلب المزيد مستقلان لكل مصدر؛ يُرتب المجموع المعروض حسب الخيار المحدد. العدد المعروض عدد النتائج المحملة، وليس إجمالي الدليل.
- لا يجلب الدليل أسماء المالكين أو صور حساباتهم. كل بطاقة تعرض بيانات النشاط التجاري فقط. إعادة التحميل تبطل الطلبات القديمة حتى لا تعيد نتائج نطاق سابق.
- صفحة المنشأة: غلاف وشعار مع عارض صور، نبذة، توثيق فعلي، تقييمات، وسائل تواصل تجاري وروابط آمنة، بحث الخرائط بالاسم والحي دون إحداثيات، خدمات مرتبطة بالمنشأة، إبلاغ، وإدارة أعمال المالك.
- إزالة بطاقة المالك المكررة. بيانات المالك لا تُحمّل إلا عند سماح RPC النطاق والخصوصية الموجود. الدردشة تتحقق مجددًا قبل إنشاء محادثة ولا ترسل رسالة تلقائية.
- أوقات العمل من أعمدة business_hours الموجودة فقط، مع احتساب توقيت السعودية والفترات بعد منتصف الليل ودوران الأسبوع. عدم وجود جدول لا يعني أن المنشأة مغلقة. لا يستخدم is_open_now القديم أو دوال غير منشورة.
- التقييمات: نجوم واضحة بلا اختيار افتراضي، تعليق اختياري محدود، تأكيد حفظ فعلي، منع النقر المتكرر، فحص التقييم السابق والملكية قبل الإرسال. لا تُعرض أسماء أصحاب التقييمات الشخصية خارج فحص النطاق؛ تظهر «أحد الجيران». التحميل على دفعات 12، والعدد الإجمالي exact. المتوسط لآخر 500 تقييم على الأكثر، ويُذكر ذلك صراحة عندما يتجاوز العدد 500.
- الخلفيات والتنقل السفلي محفوظان، والألوان تستجيب للمود، ومساحة أسفل المحتوى تراعي شريط التنقل.

## قاعدة البيانات والتحقق

- فُحص المخطط الحي للجداول businesses وservices وreviews وbusiness_hours، وسياسات reviews والقيود. لا توجد دوال business_status أو review_summary المتقدمة في المشروع الحي، لذلك لم تُربط الصفحتان بوظائف غير منشورة.
- المنشأة المحددة معتمدة وموثقة. عند الفحص لا تحتوي جدول عمل أو تقييمات أو خدمات مرتبطة؛ تظهر حالات فراغ حقيقية. لم تُضف بيانات لإخفاء هذا الفراغ.
- اختبارات جديدة: 6 حالات تشمل السعودية والفترات الليلية وحدود الأسبوع، الفترات المتعددة والفراغ، أمان الروابط والأرقام، تطبيق النطاق قبل الدفعات، اختيار المصدر والترتيب، واستكمال النتائج وفشل الاتصال.
- نجح TypeScript على مجلد المشروع الكامل بعد إصلاح أخطاء مكونات الصفحة الرئيسية في النسخة المجمعة. نجحت الاختبارات المحلية الـ178 دون فشل أو تخطٍ؛ تفاصيل نطاقها وحدودها في commerce-release-verification.md.
- تعذر إتمام الفحص المرئي: أوقفت أداة Computer Use التحكم لأنها لم تستطع التأكد من عنوان المتصفح. لم تُختبر مكالمات أو واتساب أو نشر تقييم فعلي، ولم تُرسل رسائل.

## حدود أمن التقييمات الموجودة

سياسة INSERT الحية تفرض reviewer_id=auth.uid() مع قيد نجوم 1–5. لا تفرض حاليًا منع تقييم الذات أو تكرار تقييم المنشأة في قاعدة البيانات. التحقق في النموذج يحسن الاستخدام ولا يحمي من عميل API معدل أو طلبين متزامنين من جهازين. لم يُدّع اكتمال هذه الحماية، ولم يُطبق ترحيل الأنظمة الأربعة عشر الشامل. طُبقت فقط ترحيلات محددة للأرشفة ونطاق السوق وخصوصية المنطقة؛ أسماؤها وحدودها في تقرير التحقق. لا أزرار تعديل أو حذف تقييمات لأن السياسات الحالية لا تسمح بهما.
