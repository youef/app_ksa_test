# ربط يوميات الحي بالحساب

## تجربة المستخدم
- «يومياتي» في الملف الشخصي: اليوميات النشطة والأرشيف الخاص، المشاهدات والإعجابات، قائمة المشاهدين، إغلاق الردود لكل يومية، والحذف بعد التأكيد.
- عرض اليوميات المتاحة داخل ملف الجار؛ لا يظهر القسم عند قفل الملف أو الحظر.
- رابط إعدادات اليوميات من الحساب والرئيسية، وخيارات المدينة والحي والمتابَعين وغير المشاهدة ويومياتي في دليل اليوميات.
- تحديث البيانات عند العودة إلى الحساب أو اليوميات، وإظهار أخطاء التحميل بدل نجاح وهمي.
- إعداد الردود موحّد مع profiles.allow_story_replies؛ يحترم الناشر تعطيل الردود ويبدأ جمهور الحساب الخاص بالمتابعين.
- إظهار الحسابات ذات التفضيلات المحفوظة حتى بعد إلغاء متابعتها لتظل إمكانية إلغاء كتمها متاحة.
- الكتم يطبّق في الرئيسية ودليل اليوميات. مفاتيح الحفظ تمنع التعديلات المتداخلة.
- رفض النشر عندما يفشل رفع الصورة ولا تتوفر صورة قابلة للمشاركة؛ لا تُنشر مسارات الجهاز المحلية.
- الردود تمر عبر story_replies فقط؛ أُزيل مسار إنشاء محادثة بديل عند رفض الرد.

## ترحيل قاعدة البيانات — مطبّق
`supabase/migrations/20261021154750_stories_profile_integration.sql`

أُنشئ الملف عبر Supabase CLI، ثم طُبّق على مشروع الإنتاج vkeuyompnddqfvulalkk بعد موافقة المستخدم الصريحة. يطابق اسم الملف إصدار سجل الترحيلات البعيد 20261021154750.

يتضمن:
1. جدول story_likes مع مفتاح فريد يمنع تكرار الإعجاب وسياسات RLS وحقوق محدودة للمستخدمين المسجلين.
2. تمكين صاحب اليومية من قراءة أرشيفه الخاص بعد انتهاء اليوميات.
3. تطبيق إخفاء الجمهور والحظر وخصوصية الحساب على القراءة من الخادم.
4. تطبيق إعداد الردود والرسائل وصلاحية اليومية على إدراج الرد من الخادم.
5. احترام الكتم وإيقاف تنبيهات كل حساب داخل وظيفة إشعارات النشر الحالية.

لا يحذف الترحيل يوميات أو حسابات قائمة. أصبحت الإعجابات والأرشيف الخاص وصلاحيات المشاهدة والردود والتنبيهات فعّالة على الخادم.

## التحقق
- نجحت اختبارات صلاحية الـ٢٤ ساعة وحدود الانتهاء، وفلاتر المتابعة وغير المشاهدة والحي والملكية.
- نجحت اختبارات رفض رفع المسار المحلي واحترام تعطيل الردود على مستوى الحساب.
- نجح بناء الويب عبر Expo.
- نجح فحص TypeScript للمشروع كاملًا؛ أُزيل المرجع القديم newChatBtn من صفحة الرسائل، ويستخدم الزر تنسيق HeaderAction الحالي.
- نجح tests/stories.integration.sql على قاعدة الإنتاج ضمن معاملة تنتهي بـ ROLLBACK: ملكية الأرشيف، المشاهدة العامة وللمتابعين، منع الإخفاء والحساب الخاص والزائر، حفظ الإعجاب وإزالته ومنع تكراره أو انتحال صاحبه، وصول الرد إلى محادثة، إغلاق الردود من اليومية والحساب، وإعدادات التنبيه العامة والخاصة والكتم. لم يترك الاختبار سجلات أو تفاعلات تجريبية.
- لا تتوفر جلسة مستخدم في المتصفح لاختبار النقرات داخل الملف الخاص؛ لا تُفسّر اختبارات قاعدة البيانات على أنها اختبار واجهة كامل.
- فُحص مستشار الأمان: جدول story_likes محمي بسياسات RLS، ووظيفة إشعارات اليوميات لا تُتاح للاستدعاء المباشر. توجد ملاحظات قائمة خارج هذا التغيير تتعلق بواجهات SECURITY DEFINER ووظائف أخرى. [مرجع ملاحظات العروض](https://supabase.com/docs/guides/database/database-linter?lint=0010_security_definer_view)، [مرجع صلاحيات الوظائف](https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable).
