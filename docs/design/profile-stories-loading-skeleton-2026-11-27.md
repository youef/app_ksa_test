## مشكلة UX المحددة

في `components/profile/ProfileStories.tsx` يظهر مؤشر دائري منفرد أثناء تحميل اليوميات، بينما المحتوى الفعلي عبارة عن شريط ملخص وبطاقات معاينة أفقية. لذلك لا يستطيع المستخدم توقع شكل المحتوى أو حجمه قبل اكتمال الاستعلام.

## خطة التنفيذ — تحسين واحد فقط

1. استبدال المؤشر المنفرد بهيكل تحميل ثابت يحاكي شريط الملخص وثلاث بطاقات يوميات أفقية.
2. الحفاظ على اتجاه RTL وترتيب البطاقات الأفقي والأبعاد الحالية للمعاينة؛ لا تغيير لاستعلامات Supabase أو التصفية أو الأرشيف أو الإعجابات أو الحذف أو التنقل.
3. تقديم حالة التحميل كعنصر `progressbar` مع تسمية عربية وحالة busy، وإخفاء عناصر Skeleton الزخرفية عن قارئات الشاشة.
4. عدم إضافة shimmer أو حركة؛ يظل الهيكل ثابتًا، وبالتالي لا يحتاج إلى استثناء خاص لتفضيل تقليل الحركة.
5. إضافة اختبار انحدار مركز يتحقق من وجود الهيكل ودلالات الوصول وثباته، ثم تحديث هذا التقرير بنتائج الفحوص الفعلية.

## معايير القبول

- لا يظهر Spinner منفرد في حالة التحميل.
- تتطابق بنية Skeleton مع الملخص والبطاقات الحقيقية وتبقى RTL.
- لا تُقرأ الأشكال الزخرفية بواسطة قارئات الشاشة، ويُعلن عن التحميل مرة واحدة.
- لا تتغير البيانات أو السلوك أو التنقل.
- نجاح اختبار الانحدار وTypeScript وتصدير Web وفحوص CI المتاحة قبل اعتبار الدفعة جاهزة للمراجعة.

## التنفيذ — قبل / بعد

- **قبل:** مؤشر `ActivityIndicator` منفرد بارتفاع ضمني صغير، بينما قائمة اليوميات الفعلية تتكون من ملخص وثلاثة عناصر معاينة على الأقل.
- **بعد:** شريط ملخص هيكلي وثلاث بطاقات ثابتة بارتفاع معاينة 190px وعرض 152px، مع صفوف إحصاءات شكلية؛ لا shimmer ولا حركة.
- إعلان واحد لحالة التحميل عبر `progressbar` و`accessible` و`busy`، مع إخفاء الشريط والبطاقات الزخرفية عن قارئات الشاشة.
- بقيت واجهة البيانات والاستعلامات وعمليات الردود والحذف والأرشيف والإعجابات والتنقل كما هي.
- الملفات المعدلة: `components/profile/ProfileStories.tsx` و`tests/profileStoriesLoadingDesign.test.cjs` وهذه الوثيقة فقط.
- أضيف اختبار انحدار بأربع مجموعات assertions تغطي الهيكل، وإعلان الوصول، واتجاه RTL والأبعاد، وعدم إدخال حركة.
- محاولة التشغيل المحلي لم تصل إلى GitHub بسبب فشل DNS في بيئة التنفيذ؛ لذلك ستُستخدم فحوص GitHub Actions على رأس PR للتحقق من TypeScript وWeb والاختبارات.
