# Ask form UX polish — 2026-11-20

## خطة التصميم قبل التنفيذ
- **النطاق:** شاشة إنشاء المنشور `app/ask.tsx` فقط، مع سجل التصميم واختبار تخطيط الشاشة المرتبط بها. لا تغيير في قواعد النشر أو التحقق أو البيانات.
- **المراجعة قبل:** بطاقات التصنيف (103px، نصف عرض الشاشة تقريبًا) واضحة لكن حدودها 15px ومحتواها مضغوط (11px أفقي/10px عمودي). شرائح خيارات توصيل المدارس 39px، وتغيير الموقع 40px، وأقراص الخطوة 35px؛ بعضها أقل من هدف لمس مريح 44px.
- **الاتجاه البصري:** الحفاظ على Oasis وRTL وبطاقات التصنيف ذات العمودين، مع زيادة التنفس الداخلي وتنعيم الزوايا بدل إضافة زخارف أو حركات جديدة.
- **التفاعل والإتاحة:** أهداف لمس الخيارات والموقع إلى 44px. مؤشر الخطوة إلى 40px لسهولة القراءة (غير تفاعلي). إبقاء حالات التحديد الحالية والأوصاف والإشعارات كما هي.
- **التجاوب:** استمرار العرض بعمودين ضمن عرض 560px، مع المسافات الحالية، وfooter الذي يحترم Safe Area والـ KeyboardAvoidingView. لا عرض ثابت ولا تغيير في سلوك Android/iOS.
- **المخاطر والفحوص:** تعديلات تصميمية فقط. فحص TypeScript، وتصدير Web، واختبار `askWizardLayout` المتاح، ثم مراجعة الأجهزة/لوحة المفاتيح يدويًا قبل أي دمج.

## قبل / بعد
- بطاقات تصنيف 103px / زوايا 15px / padding 11×10 → 112px / 18px / 13×12 لراحة أكبر.
- شرائح الاختيار 39px وتغيير الموقع 40px → 44px.
- مؤشر الخطوة 35px → 40px مع padding أوسع.
- تلميحات 10.5px → 11px وline-height 17px لقراءة أفضل.
