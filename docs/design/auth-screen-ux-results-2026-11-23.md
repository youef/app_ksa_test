- أضيفت حدود تركيز متكيفة مع الثيم وزر إظهار كلمة المرور بهدف لمس 44×44px.
- استبدلت تنبيهات التحقق وفشل المصادقة ورسالة تأكيد التسجيل بمنطقة رسائل داخل النموذج، معلنة لقارئ الشاشة وقابلة للمسح عند تعديل المدخلات.
