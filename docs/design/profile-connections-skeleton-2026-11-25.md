## المشكلة المرصودة

في `components/profile/ProfileConnections.tsx` تظهر نافذة المتابعين/المتابَعين بهيكل الحوار والعنوان، ثم مؤشر تحميل دائري فقط حتى اكتمال استعلام العلاقات واستعلام ملفات الأشخاص. لا توجد معاينة لشكل الصفوف أثناء التحميل الأولي، فتبدو مساحة المحتوى فارغة نسبيًا ويصعب تمييز أن قائمة بطاقات ستظهر.

## التحسين الواحد المختار

إضافة **تحميل هيكلي ثابت (skeleton) لصفوف قائمة المتابعين/المتابَعين**:
1. عند التحميل الأولي فقط، عرض أربعة صفوف RTL متوافقة مع تصميم القائمة، لكل صف دائرة صورة رمزية وخط اسم وخط وصف.
2. إعلان حالة التحميل لقارئات الشاشة باسم مناسب حسب نوع القائمة.
3. إخفاء أشكال skeleton الزخرفية عن شجرة الوصول حتى لا تُقرأ كعناصر فعلية.
4. إبقاء skeleton ثابتًا بلا shimmer أو حركة؛ هذا يحترم إعداد تقليل الحركة ويجنب وميضًا بصريًا غير ضروري.
5. أثناء تحميل صفحات إضافية، تبقى الصفوف الموجودة مرئية ويستمر مؤشر التحميل الحالي في الأسفل.

## قبل / بعد ومعايير القبول

- **قبل:** مؤشر دائري منفرد داخل حوار واسع نسبيًا؛ لا تمثيل بصري للصفوف القادمة.
- **بعد:** أربعة صفوف placeholder ثابتة بترتيب RTL وأحجام قريبة من بطاقة الشخص، مع إعلان تحميل عربي واحد لقارئ الشاشة.
- لا تغيير في استعلامات Supabase أو ترقيم الصفحات أو ترتيب العلاقات أو بيانات الخصوصية أو التنقل إلى الملف العام.
- لا تغيير في واجهة سوق الحي أو أي شاشة أخرى.
- تبقى حالات الخطأ وإعادة المحاولة والقائمة الفارغة و«عرض المزيد» كما هي.
