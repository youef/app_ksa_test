# خطة تصميم المحادثة الفردية — 2026-11-17

## النطاق
`app/conversation.tsx` و`components/chat/chatStyles.ts` و`components/chat/ChatInputBar.tsx`. اقتباس مبادئ تجربة مراسلة مألوفة من سناب وواتساب دون نسخ الهوية البصرية أو ميزات غير موجودة.

## قبل
- فقاعات شبه مستطيلة وحدود غير موحدة مع لوحة كتابة زوايا أقل استدارة.
- ارتفاع 40px للأزرار والإيموجي، وبعض مناطق اللمس أقل من 44px.
- إرسال فارغ محتمل عند رفع الصور، بسبب اعتبار رفع الوسائط كافياً لتفعيل إرسال رسالة نصية.
- مسافات التاريخ والرسائل ضيقة، وزر أحدث الرسائل بلا تلميح وصول.

## بعد
- فقاعات متمايزة للأطراف مع زوايا 20px وتباعد محسّن وبطاقة تاريخ دائرية، بألوان حيّنا الخضراء.
- محرر دائري 46px مع مرفقات 46px، زر إرسال 48px وإيموجي 44px.
- يمنع إرسال رسالة نصية فارغة أو الإرسال أثناء رفع الوسائط أو مشاركة الموقع.
- تلميحات عربية لقارئات الشاشة، مساحة إضافية أسفل الرسائل، واحترام Safe Area الحالي.

## التحقق
مراجعة شفرة المصدر وتسجيل التغييرات. TypeScript وExpo Web واختبارات الجهاز تتطلب بيئة تشغيل المشروع؛ تُذكر نتائجها الحقيقية في PR ولا يُدّعى نجاحها دون تشغيل.

## التالي
تحسين حالات الرسالة متعددة الوسائط (الصور والموقع)، وأزرار إعادة المحاولة وقراءة الرسائل.
