# خطة تحسين مركز الإشعارات — 17 نوفمبر 2026

## الأولوية
اختير `app/notifications.tsx` لأنه لم يُعالج في الدفعات السابقة (المفضلة، الدليل، الرسائل، المحادثة)، ولأن شريط الإجراءات والفلاتر وحالات الفراغ يحتاجون ضبطًا على الشاشات الصغيرة.

## قبل
- أزرار «غير المقروء» و«قراءة الكل» و«الحذف» تعتمد على padding منخفض وزر الحذف 32×32 فقط.
- بطاقات الإشعارات بزوايا 14px ومساحات داخلية ضيقة؛ العناصر المقروءة معتمة مما يقلل وضوح النص.
- حالات الفراغ لا تتيح إزالة فلتر «غير المقروء» بسرعة.
- لا توجد أوصاف وصول لبعض إجراءات الشريط؛ التخطيط الأفقي قد يزدحم على iPhone.

## التنفيذ المخطط
- استبدال صف الإجراءات بتخطيط RTL مرن ومتجاوب، ومناطق لمس لا تقل عن 44px.
- بطاقات متسقة مع Oasis: زوايا 20px، حواف هادئة، مسافات أوضح، دون تعتيم النص المقروء.
- تحسين حالة الفراغ بإجراء «عرض جميع الإشعارات» عند تفعيل الفلتر، وإضافة accessibility labels.
- تحسين ارتفاع تبويبات التصنيف واستمرار التمرير الأفقي.

## التحقق المطلوب
TypeScript (`npm run typecheck`)، تصدير Web (`npm run build`)، الاختبارات المتاحة، ومراجعة iPhone/Android/iPad/ويب. لا دمج أو نشر قبل اجتياز الفحوص والمراجعة.

## التالي
واجهة البحث `app/search.tsx`؛ مراجعة تبويبات النتائج وإدخال البحث وحالات التحميل.
